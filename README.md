# Cyclistic_case_study
A dummy case study related to Google Data Analytics certificate.
It is about a fictional company, Cyclistic. The goal would be turn casual riders into annual members.
The aim of the analysis is to compare the behavior of casual riders and annnual members.

Data source: https://divvy-tripdata.s3.amazonaws.com/index.html
