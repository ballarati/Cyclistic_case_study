# Cyclistic_case_study
A dummy case study related to Google Data Analytics certificate.
It is about a fictional company, Cyclistic. The goal would be turn casual riders into annual members.
The aim of the analysis is to compare the behavior of casual riders and annnual members.

Data source: https://divvy-tripdata.s3.amazonaws.com/index.html

License of the original data: https://divvybikes.com/data-license-agreement


For the analysis, I cleaned the data (see more details in the report):
- removed data where enpoint GPS was missing
- removed data where travel time is less than 5 minutes.

The cleaned data can be found here: https://drive.google.com/drive/folders/1jT7xhM8r1TCJBcoDMDotK8U5zJmGYTp0?usp=drive_link.
